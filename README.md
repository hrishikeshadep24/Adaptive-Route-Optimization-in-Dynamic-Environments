# Adaptive Route Optimization in Dynamic Environments

Research framework for studying route-update strategies under dynamic conditions.

## Quick Start

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pytest -q
```

## Structure

- `src/` - Core algorithms and simulation engine
- `docs/` - Research documentation (blueprint, phase plan, literature notes)
- `tests/` - Unit and integration tests
- `configs/` - Experiment configurations
- `data/` - Generated instances and benchmarks
- `results/` - Raw and processed experiment outputs
- `notebooks/` - Analysis notebooks
- `app/` - Streamlit demo (Phase 9)
